jetio

Adds Torrentio releases as selectable versions on items in your jetio library.

When off, items fall back to the single release chosen by jetio.
Jellyfin repackages the stream instead of sending players to it directly. Video and audio are copied, not re-encoded. Turn this on if external subtitles are listed but never appear — some clients, including the Android TV app, cannot add subtitles to a stream Jellyfin never handled. Costs a little bandwidth through the server and makes seeking slower.
For example http://192.168.1.10:9000 — must be reachable from this server and from playback devices.
Lookups happen while the item page loads. Keep this short.
